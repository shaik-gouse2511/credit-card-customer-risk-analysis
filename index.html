Credit Card Customer Risk Analysis

Simple Power BI Ready Report (Dataset: 5,993 Test Accounts)

🛠️ Power BI Step-by-Step Creation Blueprint

Takes ~5-10 minutes in Power BI Desktop
Step 1: Import Clean CSV Click Get Data → Text/CSV → select:
outputs/power_bi_credit_card_risk.csv
Click Load. (All names are already cleaned into plain English!)
Step 2: Create 4 DAX Measures Click New Measure for each:
Total Customers = COUNTROWS('power_bi_credit_card_risk')
Default Rate = AVERAGE('power_bi_credit_card_risk'[Is_Default])
High Risk % = DIVIDE(CALCULATE([Total Customers], 'power_bi_credit_card_risk'[Risk_Level] = "High Risk"), [Total Customers], 0)
Avg Limit = AVERAGE('power_bi_credit_card_risk'[Credit_Limit])
Step 3: Insert Visuals (Drag & Drop)
  • Card Visuals (Top): [Total Customers], [Default Rate], [High Risk %], [Avg Limit].
  • Donut Chart: Legend = Risk_Level, Values = [Total Customers].
  • Clustered Bar Chart: Y-axis = Payment_Status, X-axis = [Default Rate].
  • Clustered Column Chart: X-axis = Age_Group, Y-axis = [Total Customers].
  • Table Visual: Drag Customer_ID, Credit_Limit, Age, Payment_Status, Risk_Level, Actual_Default.
